O TaskFlow é um sistema desenvolvido em Python para ajudar as pessoas a organizar suas tarefas diárias de forma simples e prática.

 Funcionalidades
Tela de login
Cadastro e gerenciamento de tarefas
Calendário para agendamentos
Relatórios de produtividade
Armazenamento de tarefas

 Tecnologias Utilizadas
Python
Tkinter
SQLite
 Objetivo
 
Facilitar a organização das atividades, ajudando os usuários a controlar suas tarefas e acompanhar seu progresso.
